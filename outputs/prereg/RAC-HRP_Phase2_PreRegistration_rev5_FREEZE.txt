Claim stated narrowly: at |T| = 112, expanding the grid from {2,3,4,6} to {2,…,12} does not change the reported cutoff because q = 2 attains the maximum in the simulated draws. 4.  D_VI bootstrap — fully frozen
D_VI is a hard selection gate, so its bootstrap must be exactly reproducible. VI is computed against a counterfactual: hypothetical clusters are recomputed at every eligible rebalance, including non-triggered ones.
Element
Frozen value
Bootstrap
circular block bootstrap (edge observations not under-weighted)
Block length
Politis-White automatic selection, consistent with the Phase 4 inference protocol
Resampling unit
the PAIR (VI_t, I_t) resampled jointly in blocks — trigger/VI alignment preserved
Replications
B_boot = 10,000
RNG / seed
numpy PCG64; seed = 20260817 + 2000 + c, c = index of γ in {0.5,1.0,1.5,2.0}
Hypotheses
H0: D_VI ≤ 0   vs   H1: D_VI &gt; 0   (one-sided)
Null centering
bootstrap replicates centred by subtracting the observed D̂_VI
p-value
p = (1 + #{b : D*_b − D̂_VI ≥ D̂_VI}) / (B_boot + 1)
Multiplicity
Holm step-down across the four γ at family-wise α = 0.05
Holm is used rather than Bonferroni because the trigger sets are highly dependent across γ. A candidate passes iff D̂_VI &gt; 0 and its Holm-adjusted p &lt; 0.05.

Selection (frozen): among γ ∈ {0.5, 1.0, 1.5, 2.0}, select the value closest to the inherited γ = 1.0 passing every hard criterion in §2; ties broken toward the larger γ. If none passes, Phase 2 stops — the “least bad” candidate is not selected.
Null failure (frozen): if the selected γ fails Null Gate v2, Phase 2 stops. No fall-through.
Procedure: (1) structural diagnostics only, no returns/Sharpe/drawdown computed or displayed; (2) apply the selection rule automatically in code; (3) write selected γ and diagnostics to a hashed frozen record; (4) run Null Gate v2 at the selected γ — the existing verdict applies only to γ = 1.0 and is not inherited; (5) only on a pass, generate performance output.
