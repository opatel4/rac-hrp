3.  Separation statistic and its frozen Monte Carlo (condition B)
Maximisation is over schedule period and phase. Phase matters: a trigger firing exactly every second rebalance on odd-indexed dates scores J* = 0.252 without phase adjustment (passing) and J* = 1.000 with it (correctly caught).
Grid: q ∈ {2,…,12} — the systematic set, so the claim is not limited to a few hand-picked periods. The threshold is identical to the narrow {2,3,4,6} set because at these event counts the q = 2 schedule always attains the maximum, so the wider search costs nothing.

4.  Multiplicity adjustment on the inferential gate (condition C)
D_VI is the only explicitly inferential structural criterion and it is evaluated for four candidate γ. Using an unadjusted 95% interval four times and then selecting among the passers introduces a multiple-testing problem inconsistent with the project&apos;s anti-snooping stance.
Block-bootstrap p-values for H0: D_VI ≤ 0 are computed for all four γ (Politis-White automatic block length, consistent with the Phase 4 inference plan).
The four p-values are adjusted by the Holm step-down procedure at family-wise α = 0.05. Holm is chosen over Bonferroni because the trigger sets are highly dependent across γ and Bonferroni would be needlessly conservative.
A candidate passes cluster informativeness iff its Holm-adjusted p &lt; 0.05 and D_VI &gt; 0.
VI is computed against a counterfactual: hypothetical clusters are recomputed at every eligible rebalance, including non-triggered ones, so triggered and non-triggered structural change are directly comparable.

Selection rule (frozen): among γ ∈ {0.5, 1.0, 1.5, 2.0}, select the value closest to the inherited γ = 1.0 passing every hard criterion in §2; ties broken toward the larger γ. If none passes, Phase 2 stops — the “least bad” candidate is not selected.
Null-failure stopping rule (frozen): if the selected γ fails Null Gate v2, Phase 2 stops. No fall-through to the next candidate — fall-through would constitute a second unregistered selection procedure operating on null-gate outcomes.
6.  Procedure
1. Structural diagnostics only. No returns, Sharpe or drawdown computed or displayed.

3. Write selected γ and full diagnostics to a hashed frozen record.
4. Run Null Gate v2 at the selected γ. The existing verdict applies only to γ = 1.0 and is not inherited.
5. Only on a pass, generate performance output.
